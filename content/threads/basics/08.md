توی ترد قبلی از تفاوت عبارت و عملیات گفتیم و رسیدیم به **Evaluation** یا همون **ارزیابی**. 

فهمیدیم که Evaluation در حقیقت **تعیین مقدار یک عبارت یا Expression** هست.

<br/> 

خیلی چیز دوری نیست. مثلا وقتایی که گفتی 
$$ 3+5 = 8$$
در واقع عبارت `5 + 3` رو Evaluate کردی.

<mark>
 هم 8 و هم 5 + 3 از نظر مقدار باهم برابر هستن. اما یکی مقداره و دیگری عبارت.
</mark>


<br/>
<br/>

اگر که `5 + 3` رو به کامپیوتر بدیم اول از همه اون رو یه عبارت (Expression) تشخیص میده. **بعد طبق قوانین زبان عبارت رو Evaluate میکنه تا به مقدار `8`برسه.** 

بیشتر برنامه هایی که اجرا میکنیم پر از **Expression** ها هستن. کامپیوتر همه اون ها رو Evaluate میکنه و براش فرقی نمیکنه که نتیجه ای که بدست میاد عدد هست یا نه. یعنی مثلا یک عبارت میتونه یک مقدار منطقی برگردونه مثل True و False. 


{{< readmore type="" title="یکم بیشتر بدونید" open="false" >}}
اگه تا حالا یه شرط با if نوشته باشی میدونی که معمولا True و False برمیگردونه. 
مثلا اگر بنویسم که

`if (major == "CS")`

شرط من میگه آره رشته کامپیوتر هست یعنی **True** یا میگه نه آقا چی چی میگی نیست یا همون **False**.

<br/>

کامپیوتر شرط ما رو Evaluate میکنه و اگر True باشه وارد بدنه if میشه و اگر False باشه ازش رد میشه. 

{{< /readmore >}}

پس نتیجه‌ی Evaluation همیشه هم عدد نیست.
